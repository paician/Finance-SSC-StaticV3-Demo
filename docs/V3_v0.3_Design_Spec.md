## 3. 假期與重要日程

- 右側採 **Cards / Month** 切換；月份可上月／下月，並可按國家／地區篩選。
- 顯示 `日期`、`日程名稱`、`Area` 標籤；不要求事先判斷公司別。
- 預計權威來源：Lark Global 共用行事曆。**目前尚未確認 Calendar API 權限、事件可讀性、假日覆蓋或是否有跨國共享日曆的 API 訪問範圍**。
- 設計需考慮同一日期多事件、公司／地方假日適用性差異、更新時間與 API 失敗降級。
- Demo 內的日程不可作為法定假日或公司政策依據；不得標示為已同步。

## 4. HR 出缺勤（Future Data Contract）

- 正式資料來源可能是 BIPO 或其他 HRIS；以所屬公司／國家動態取得 Provider、更新時間及資料鮮度。
- SSC 可考慮將授權的摘要同步到自有資料服務與快取，避免每次開頁同步向 HRIS 查詢；此為架構候選，尚未決議。
- 無有效資料時顯示「暫無可用資料／前往原系統」，**不得推斷為正常出勤**。
- Manager 僅能查看後端授權的團隊摘要；請假原因等個資不宜公開。

## 5. 差旅查詢（Future Data Contract）

- Demo：示意姓名／地區篩選，不發送請求。
- Production：先確認差旅資料擁有者、最小必需欄位、更新頻率、一般員工／主管可見範圍；再決定是否 PostgreSQL 索引、快取或 Backend Proxy。
- 搜尋不能僅靠前端下拉 Manager 角色決定敏感資料授權。
